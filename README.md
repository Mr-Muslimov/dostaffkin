# Dostaffkin

Веб-приложение сервиса доставки посылок **между странами и внутри стран**. Пользователь может рассчитать стоимость доставки по маршруту, оформить заявку и отследить статус отправления по номеру.

> Безопасно. Быстро. В целости и сохранности!

## Возможности

- **Главная страница** — краткое описание сервиса, преимущества и кнопки перехода к оформлению и отслеживанию доставки.
- **Оформление доставки** (`/order`):
  - ввод адресов «откуда» и «куда» с подсказками адресов Яндекс.Карт;
  - выбор размера посылки (XS–MAX) и скорости доставки (обычная / приоритетная);
  - расчёт маршрута и стоимости по фактическому расстоянию через `ymaps.multiRouter`;
  - форма отправителя (имя, телефон, комментарий) и создание заявки.
- **Отслеживание посылки** (`/track`):
  - поиск отправления по номеру;
  - отображение маршрута (откуда → куда) и истории статусов с иконками.

## Расчёт стоимости

Стоимость зависит от размера посылки (тариф за километр и минимальная цена) и расстояния маршрута:

```
total = max(min, ceil(км × rate))
```

Для приоритетной доставки стоимость увеличивается на 15 %, а срок — сокращается примерно на 30 %. Размеры и тарифы заданы в `src/app/pages/order/order.config.ts`.

## Технологии

- **Angular 21** (standalone-компоненты, signals, reactive forms, router)
- **RxJS** и `HttpClient` для работы с API
- **Яндекс.Карты JS API** — построение маршрута и подсказки адресов
- **Vitest + jsdom** для тестов, **Prettier** для форматирования

## Требования

- Node.js (LTS) и npm
- Проект настроен на `npm@10.9.2` (см. `packageManager` в `package.json`)

## Запуск и сборка

```bash
npm install       # установка зависимостей
npm start         # dev-сервер (ng serve)
npm run build     # production-сборка
npm test          # тесты
```

Сборка складывается в каталог **`docs/`** с `baseHref` `/dostaffkin/` — из него сайт публикуется через **GitHub Pages**.

## Внешний API

Приложение обращается к серверу `testologia.ru` (см. `src/app/services/delivery-api.ts`):

| Метод | Назначение |
| --- | --- |
| `POST https://testologia.ru/delivery/create` | создание заявки на доставку, возвращает её идентификатор |
| `GET https://testologia.ru/delivery/info?id=<номер>` | получение статуса и маршрута отправления |

## Структура проекта

```
src/
  app/
    app.config.ts            # конфигурация приложения (router, http)
    app.routes.ts            # маршруты: home / order / track
    header/                  # шапка сайта с навигацией
    pages/
      home/                  # главная страница
      order/                 # оформление доставки + расчёт стоимости
        order.config.ts      # размеры посылок и тарифы
      track/                 # отслеживание посылки
    services/
      delivery-api.ts        # работа с внешним API доставки
  index.html                 # точка входа, подключение Яндекс.Карт
  main.ts                    # bootstrap приложения
  styles.css                 # глобальные стили
public/                      # статические ресурсы (шрифты, изображения, иконки)
docs/                        # собранная production-версия для GitHub Pages
```

## CI

В репозитории настроены два GitHub Actions workflow (`.github/workflows/`), которые при каждом пуше сравнивают код с эталонными репозиториями курса (`intensive-front/l5ref` и `intensive-front/l6ref`) и формируют отчёт о различиях.
